# 🌱 MindMap Youth

**MindMap Youth** és una plataforma web interactiva i dinàmica dissenyada per a ajudar els adolescents i joves a identificar, entendre i autoregular les seues emocions i pensaments. Amb un disseny visual atractiu, modern i en tons pastel, l'aplicació ofereix recursos pràctics i eines interactives de suport emocional.

---

## 🚀 Funcionalitats Principals

La plataforma es divideix en diferents seccions i aplicacions interactives:

### 1. 📊 Mapa de Recursos i Conductes Alternatives
* Guies i consells ràpids per a gestionar crisis o estats de dolor emocional intens basats en les recomanacions de l'OMS.
* Passos clau per a l'autoregulació: *Pausa, Calma, Connecta, Seguretat i Professionals*.

### 2. 🕵️‍♂️ El Detectiu dels Pensaments
* Una eina interactiva per a analitzar aquells pensaments que ens aclaparen, qüestionar-los de forma objectiva i buscar alternatives més saludables.

### 3. 🌡️ El Termòmetre de les Emocions
* Un termòmetre interactiu on els usuaris poden prémer diferents nivells d'activació emocional (*Calma, Inquiet, Alerta, Pànic*) per a rebre consells i tècniques de regulació immediates segons el seu estat.

---

## 🛠️ Tecnologies Utilitzades

Aquest projecte s'ha desenvolupat utilitzant tecnologies web estàndard, prioritzant la lleugeresa, el disseny responsiu i la facilitat d'ús:

* **HTML5:** Estructura semàntica de totes les seccions i aplicacions.
* **CSS3:** Estils personalitzats amb una paleta de colors pastel, disseny flexible (*Flexbox*) i tipografies arrodonides per a crear un entorn visualment segur i acollidor.
* **JavaScript (Vanilla):** Lògica de programació per a gestionar la interactivitat del termòmetre, les situacions dinàmiques i la navegació de l'usuari.
